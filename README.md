# Roast & Code Cafe

A simple coffee shop website showcasing CI/CD integration.

## Description

Roast & Code Cafe is a static website built with HTML and CSS. It demonstrates a simple web presence for a coffee shop while using CI/CD practices for automated deployment.

## Technologies

- HTML — 62%
- CSS — 38%
- CI/CD

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/InventiveBear/roast-and-code-cafe.git
   cd roast-and-code-cafe
   ```

2. Open `index.html` in a browser.

Alternatively, use a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
